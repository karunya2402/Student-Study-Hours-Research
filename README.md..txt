# Student Study Hours vs Exam Performance

## Research Question
Is there a relationship between the number of hours students study and their exam scores?

## Dataset
This project uses a synthetic dataset containing 10 student observations.

The dataset contains two columns:
- Study_Hours
- Exam_Score

## Objective
To analyze the relationship between study hours and exam performance using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- SciPy
- Google Colab

## Analysis Methods
- Data creation
- Data visualization using scatter plot
- Correlation analysis
- Pearson correlation test

## Conclusion
The synthetic dataset shows a positive relationship between study hours and exam scores.

## Disclaimer
This dataset is synthetic and created for educational and research practice.
It does not represent real students.
